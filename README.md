# Playwright Python Automation Framework

## 📌 Project Overview

This project is an end-to-end web automation framework developed using **Playwright with Python** following the **Page Object Model (POM)** design pattern.

The framework automates major user workflows of the Rahul Shetty Academy E-Commerce application and demonstrates industry-standard automation practices.

---

## 🚀 Tech Stack

- Python
- Playwright
- Pytest
- Page Object Model (POM)
- JSON
- Git
- Azure DevOps

- global runtime variable managed through conftest.py
- Browser selection through Terminal
- centralized configuration of all test cases.
- Easy execution across different environments.
- Browser value decided during run time
- Runing test parallely and sequence mode
- Generate HTML Report 
- Playwright Traceviewer -to generate logs,screenshots of the test in zip file

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/mani2013kum/playwright-python-framework.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Install Playwright browsers

```bash
playwright install
```

---

## ▶️ Execute Tests

Run all tests

```bash
pytest
```

Run a specific test

```bash
pytest tests/test_webapi.py
```
